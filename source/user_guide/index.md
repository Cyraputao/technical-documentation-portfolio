
# VS Code Markdown User Guide

## 1. Project Overview

本项目是一份面向 Markdown 初学者的 Visual Studio Code 用户操作手册，主要介绍如何使用 VS Code 创建、编辑和预览 Markdown 文件，以及如何处理常见操作问题。

手册通过分步骤说明和配套操作截图，展示 Markdown 文档的基本编辑流程，帮助用户熟悉文档编写环境并完成基础操作。

## 2. Project Objectives

本手册旨在：

- 介绍 VS Code 中 Markdown 文件的基本创建与编辑方法。
- 说明 Markdown 预览功能的使用方式及操作步骤。
- 整理常见操作问题及其解决方法。
- 通过清晰的步骤说明和截图，提高操作指引的可读性和实用性。

## 3. Guide Contents

本手册包含以下四个部分：

### 3.1 Create a Markdown File

介绍如何在 VS Code 中创建 Markdown 文件，包括打开项目文件夹、新建文件及保存文件等操作。

### 3.2 Edit Markdown Content

介绍 Markdown 文档的基本编辑方法，包括标题、段落、列表等常用文本结构的编写。

### 3.3 Preview Markdown

介绍如何使用 VS Code 内置预览功能查看 Markdown 文档的排版效果，以及如何在编辑过程中同步检查文档内容。

### 3.4 Troubleshooting

整理 Markdown 文件创建、编辑和预览过程中可能遇到的常见问题，并提供相应的排查方法。

## 4. Reference Sources

本手册主要参考以下官方资料：

- Visual Studio Code Documentation: https://code.visualstudio.com/docs
- Markdown Guide: https://www.markdownguide.org/

## 5. Project Note

本手册为个人技术文档编写实践作品，内容根据 VS Code 的实际操作流程整理，并配有自行制作的操作截图。

手册旨在展示基础软件操作说明、步骤组织、截图标注及技术文档编写能力，不代表 Visual Studio Code 官方文档。
