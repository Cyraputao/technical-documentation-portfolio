# 常见问题与故障排查

本节整理了使用 VS Code 编辑和预览 Markdown 文件时可能遇到的问题，并提供相应的检查方法和解决步骤。

## 1. Markdown 预览窗口无法打开

**问题描述：**

点击预览按钮或使用快捷键后，Markdown 预览窗口没有正常显示。

**可能原因：**

- 当前打开的文件不是 Markdown 文件。
- 快捷键操作不正确。
- 编辑器窗口没有正确响应操作。

**解决方法：**

1. 检查当前文件的扩展名是否为 `.md`。
2. 确认当前活动编辑器打开的是目标 Markdown 文件。
3. 尝试使用菜单中的 Open Preview 命令重新打开预览。
4. 如果问题仍然存在，重新加载 VS Code 窗口。

## 2. Markdown 预览内容显示不正确

**问题描述：**

预览窗口中的标题、段落或列表没有按照预期格式显示。

**可能原因：**

- Markdown 语法格式不正确。
- 标题标记与文本之间缺少空格。
- 段落或列表之间缺少必要的空行。

**解决方法：**

1. 检查 Markdown 源文件中的语法。
2. 确认标题标记 (#) 后有空格。
3. 检查列表标记和段落之间的空行。
4. 重新查看预览结果。

## 3. Markdown 图片无法显示

**问题描述：**

在预览窗口中，图片没有正常显示。

**可能原因：**

- 图片文件不存在。
- 图片路径填写错误。
- 图片文件名或扩展名与实际文件不一致。

**解决方法：**

1. 确认图片文件已经保存在项目目录中。
2. 检查 Markdown 文件中的图片路径。
3. 确认图片文件名和扩展名正确。
4. 重新打开预览，检查图片是否正常显示。

图片的 Markdown 语法示例：

```markdown
![图片说明](images/example.png)
```

## 4. Markdown 链接无法打开

**问题描述：**

点击 Markdown 文档中的链接后，无法打开目标页面。

**可能原因：**

- 链接地址填写错误。
- 目标网页无法访问。
- 本地文件链接路径不正确。

**解决方法：**

1. 检查链接地址是否完整。
2. 确认 URL 中没有多余的空格或错误字符。
3. 尝试在浏览器中直接打开目标网址。
4. 如果是本地文件链接，检查目标文件是否存在。

## 5. 编辑内容后预览没有更新

**问题描述：**

修改 Markdown 源文件后，预览窗口没有显示最新内容。

**解决方法：**

1. 确认修改内容已经输入到正确的文件中。
2. 检查预览窗口是否对应当前编辑的文件。
3. 尝试重新打开 Markdown 预览。
4. 如果问题仍然存在，重新加载 VS Code 窗口。

## 6. 本节小结

遇到 Markdown 编辑或预览问题时，建议先检查文件类型、Markdown 语法和文件路径，再根据具体情况重新打开预览或加载编辑器。

通过掌握基本的故障排查方法，用户可以更高效地完成 Markdown 文档的编辑与预览。
